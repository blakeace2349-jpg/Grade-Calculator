# Student Grade Calculator

## Description
A beginner Java program that calculates a student's
total score, average score, and grade for three subjects.

## Features
- Accepts a student's name
- Accepts three subject scores
- Calculates total and average
- Assigns a grade based on the average
- Displays the results

## Technology
Java
Apache NetBeans

## How to Run
1. Open the project in Apache NetBeans.
2. Run the StudentGradeCalculator class.
3. Enter the student's name and three subject scores.
4. View the calculated results.
